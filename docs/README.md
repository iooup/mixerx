# Mixerx documentation

Mixerx brings a two-deck DJ Console and a music-reactive visual Stage into the
browser. Start with the [project overview](../README.md) to run it and try a mix.

## Using Mixerx

- [Privacy and data](privacy.md): local audio, browser storage, agent access, and the video embed.
- [MIDI controllers](midi.md): connect a controller, learn controls, and understand soft takeover.
- [Crowd overlays](crowd-pets.md): characters, formations, motion, and saved settings.
- [Cinematic scenes](cinematic-scenes.md): the four image-backed worlds and their controls.
